# Run start times

Each directory in this folder was originally named `{base}_{yymmdd}_{HHMM}_{rest}`. The `_HHMM` segment has been stripped to make analysis tables cleaner — this file records the original start time for each run.

`HHMM` is the start time of the run (24-hour clock, in the local timezone of the host that ran the job). The `yymmdd` portion is preserved in the directory name.
